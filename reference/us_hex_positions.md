# Coordinates to center each state's hexagon

A manually created list of 'x' and 'y' coordinates to place the hexagons
representing each state in the USA. These are relative positions from
each of the other states.

## Usage

``` r
us_hex_positions
```

## Format

A tibble with 4 variables and 51 rows:

- state:

  Two letter state abbreviation

- x:

  Sets the 'x' position

- x:

  Sets the 'y' position

- state_name:

  Name of the state
