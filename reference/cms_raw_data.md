# Medicare list of hospitals

A list of hospitals in the USA provided by Medicare.

## Usage

``` r
cms_raw_data
```

## Format

A tibble with 9 variables and 5,336 rows:

- facility_id:

  Hospital's ID as per Medicare

- facility_name:

  Hospital's name

- address:

  Hospital's address

- city:

  Hospital's city

- state:

  Hospital's two letter state abbreviation

- zip_code:

  Hospital's Zip Code

- county_name:

  Name of the county

- phone_number:

  Hospital's phone number

- hospital_type:

  Type of care the hospital provides
