## Data

- [`us_atc_county_polygons`](https://sol-eng.github.io/accesstocare/reference/us_atc_county_polygons.md)
  : Coordinates to draw counties
- [`us_atc_model`](https://sol-eng.github.io/accesstocare/reference/us_atc_model.md)
  : Linear regression model that compares hospitals and population in a
  given US county
- [`us_atc_state_polygons`](https://sol-eng.github.io/accesstocare/reference/us_atc_state_polygons.md)
  : Coordinates to draw state's hexagons
- [`us_counties`](https://sol-eng.github.io/accesstocare/reference/us_counties.md)
  : List of US Counties
- [`us_hex_polygons`](https://sol-eng.github.io/accesstocare/reference/us_hex_polygons.md)
  : Position of the 6 corners for each state's hexagon
- [`us_hex_positions`](https://sol-eng.github.io/accesstocare/reference/us_hex_positions.md)
  : Coordinates to center each state's hexagon
- [`us_hospitals`](https://sol-eng.github.io/accesstocare/reference/us_hospitals.md)
  : List of hospitals in the USA
- [`us_large_cities`](https://sol-eng.github.io/accesstocare/reference/us_large_cities.md)
  : List of large cities
- [`us_states`](https://sol-eng.github.io/accesstocare/reference/us_states.md)
  : List of states in the USA
- [`cms_raw_data`](https://sol-eng.github.io/accesstocare/reference/cms_raw_data.md)
  : Medicare list of hospitals
