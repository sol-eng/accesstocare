# List of hospitals in the USA

List of hospitals in the USA

## Usage

``` r
us_hospitals
```

## Format

A tibble with 9 variables and 4,669 rows:

- facility_id:

  Hospital's ID as per Medicare

- facility_name:

  Hospital's name

- address:

  Hospital's address

- city:

  Hospital's city

- zip_code:

  Hospital's Zip Code

- fips:

  County FIPS

- state:

  Hospital's two letter state abbreviation

- county_name:

  Name of the county

- state_name:

  Name of the state
